# Kapsoit Dental Care — advert for dental workers

This project is an advert for dental workers and dental professionals in Kapsoit. It presents a sample online showcase and invites dental practices or practitioners to get their business or skills online.

## Preview

Open `index.html` directly in a browser, or use the VS Code Live Server extension for a preview that refreshes as you save edits. This project is plain HTML, CSS, and JavaScript; it does not require a build or package installation.

## WhatsApp contact

The contact button opens a WhatsApp message to 0717 452 095 about getting a dental business or professional skills online.

## Before publishing

- Confirm the business name, services, location, and any professional details with the intended dental practice.
- Replace “Kapsoit Dental Care” if customizing the site for a particular practice.
- Confirm the contact number is the intended public WhatsApp line.

The smiling tooth is an inline SVG illustration. It does not need external image files.
